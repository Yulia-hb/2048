# 2048 Puzzle Game

A classic 2048 tile-merging puzzle game built with Unity. This project focuses on clean code architecture, data matrix manipulation, and mobile-ready user interface development.

## 🛠 Tech Stack
* **Engine:** Unity
* **Language:** C#
* **UI System:** Unity UI (uGUI) with adaptive layouts for various screen resolutions.

## 🎯 Implemented Features
* **Core Gameplay Loop:** Full implementation of the classic 2048 logic, including tile movement, generation, and value calculation.
* **Tile Merging & Score System:** Algorithmic calculation of grid states with real-time score tracking.
* **Input Handling:** Multi-platform input support, optimized for both **Touch** (mobile) and **Keyboard** (PC) controls.
* **Architecture:** Codebase organized with a strong emphasis on readability, maintainability, and clean separation of concerns.
